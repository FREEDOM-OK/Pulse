# 生活记录（my-life-app）

只在自己手机上使用的本地生活记录 App：今日计划、健身、饮食、游戏、首页总览、日历回顾。
**不登录、不联网、不上云**，所有数据保存在手机本地 SQLite。

> 需求与验收标准见项目上一级目录的 `PRD.md`（v1.0 原版）与 `PRDv1.1.md`（v1.1 改版方案），开发计划见同目录的 `DEV_PLAN.md`。

## 运行

```bash
cd my-life-app
npm install
npx expo start
```

- 手机：安装 **Expo Go**，与电脑连同一个 Wi-Fi，扫终端二维码。
- 浏览器预览：`npx expo start --web`，打开 `http://localhost:8081`（Web 端用 sql.js + localStorage 模拟，仅供开发预览）。

## 功能

| Tab | 能做什么 |
|---|---|
| 首页 | 今日计划摘要、快速备忘（标签 / 置顶）、健身 / 饮食 / 游戏摘要、迷你月历入口 |
| 今日计划 | 按天任务：勾选完成、编辑、删除、顺延；可选时间；一次添加到 3 / 7 天 |
| 健身 | 动作库按部位分组，含单独一栏「自定义类」；44 个基础必备动作永久保留（清空数据也不删）；待训练清单跨日期常驻，卡片右下角显示练的部位；按组动作填次数 × 重量，有氧等按时间动作填运动分钟；已完成按所选日期记录、左滑删除；日期条与月历上有训练的日子带圆点 |
| 饮食 | 按早 / 中 / 晚 / 加餐记录，文字 + 可选热量，自动汇总当日总热量 |
| 游戏 | 想玩清单 → 点「玩了」用滚轮选时长（默认 0）、选游玩日期（默认今天）、填体验与 1~5 星 → 进入已玩记录；行左滑可编辑 / 删除；列表空白处左右滑动切换两个页签 |
| 设置 | 健身默认次数 / 重量、手动备份、导入（整体替换）、清空数据、主题（跟随系统 / 浅色 / 深色） |
| 日历回顾 | 月历四色点（计划蓝 / 健身橙 / 饮食绿 / 游戏紫），点某天看当天全部明细 |

## 数据与备份

- 数据存在本机 SQLite，杀进程、重启后不丢。
- **备份**：设置 → 备份数据 → 生成 `生活App备份-YYYY-MM-DD.json`（安卓走系统分享面板，自行选保存位置）。
- **导入**：设置 → 导入备份 → 选文件 → 确认后整体替换；**导入和清空前都会自动备份一份**（安卓在 App 私有目录 `auto-backups/`）。
- 导入只认文件内容（JSON），不认扩展名：即使备份文件被文件管理器改名成 `.md` 也照样能导入。
- 换手机：旧手机导出备份 → 通过任意方式把文件传到新手机 → 新手机导入。

## 测试

```bash
npm test          # 数据层 / 校验 / 备份等单元与集成测试（Vitest + 真实 SQLite）
npm run test:e2e  # 无头 Chrome 跑真实界面流程（需要先启动 http://localhost:8090 的开发服务器）
```

E2E 覆盖：今日计划增删改查与持久化、健身打卡与左滑删除、饮食汇总、游戏「玩了」流程（滚轮时长 / 游玩日期 / 左右滑动切页签）、首页备忘置顶、日历回顾、健身默认值、主题切换与清空数据。
