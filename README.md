# Pulse（原「生活记录」）

只在本人手机上使用的本地生活记录 App：今日计划、健身、课表、游戏、首页、日历回顾、个人资料与个性化外观。
**不登录、不联网、不上云**，所有数据保存在手机本地 SQLite。

> 需求与验收标准见项目上一级目录的 `PDR.md`（v1.3.0）。工程目录与备份内的应用标识仍保留 `my-life-app`，用于兼容旧备份。

## 运行

```bash
cd my-life-app
npm install
npx expo start
```

- 手机：安装 **Expo Go**，与电脑连同一个 Wi-Fi，扫终端二维码。
- 浏览器预览：`npx expo start --web`，打开 `http://localhost:8081`（Web 端用 sql.js + localStorage 模拟，仅供开发预览）。

## 功能

| Tab | 能做什么 |
|---|---|
| 首页 | 两页上下滑动：第一页问候 + 今日计划框（可直接勾选）+ 「添加事件」「去健身」两个方框 + 游戏通栏框；第二页是完整日历回顾（点顶部「⌃」或下拉回第一页） |
| 今日计划 | 按天任务：点击条目标记完成、长按菜单编辑 / 删除；可选时间；一次添加到 3 / 7 天 |
| 健身 | 动作库按部位分组，含「自定义类」；44 个基础动作永久保留；待训练跨日期常驻，卡片显示练的部位；按组计填次数 × 重量，按时间计填运动分钟；已完成组支持长按删除；日期条与月历有记录的日子带圆点 |
| 游戏 | 想玩清单 → 点「玩了」滚轮选时长（默认 0）、选游玩日期（默认今天）、填体验与 1~5 星 → 已玩记录；两页可左右滑动切换；行用长按菜单编辑 / 删除 |
| 设置 | 顶部账号区（长按进入个人资料）、健身默认次数 / 重量、手动备份、导入（整体替换）、清空数据、主题（跟随系统 / 浅色 / 深色） |
| 日历回顾 | 月历四色点（计划蓝 / 健身橙 / 事件绿 / 游戏紫），点某天看当天全部明细；首页第二页内嵌同一套面板 |

事件（重大消费 / 重大购物 / 今日好饭）只在首页「添加事件」里创建，日期固定为当天，目前支持添加与查看。

## 数据与备份

- 数据存在本机 SQLite（schema v3：`events` 表 + `profile.*` 设置；旧的 `diet_records`、`memos` 已删除，饮食记录迁移成「今日好饭」事件）。
- **备份**：设置 → 备份数据 → 生成 `生活App备份-YYYY-MM-DD.json`（安卓走系统分享面板，自行选保存位置）。
- **导入**：设置 → 导入备份 → 选文件 → 确认后整体替换；**导入和清空前都会自动备份一份**（安卓在 App 私有目录 `auto-backups/`）。
- 导入只认文件内容（JSON），不认扩展名：备份被改名成 `.md` 也照样能导入；旧版 v1/v2 备份里的 `dietRecords` 会自动转成事件，`memos` 忽略，自定义头像不进备份。
- 换手机：旧手机导出备份 → 通过任意方式传到新手机 → 新手机导入。

## 测试

```bash
npm run verify    # 单测 + tsc --noEmit + expo lint
npm run test:e2e  # 无头 Chrome 跑真实界面流程（需先启动 http://localhost:8090 的开发服务器）
```

E2E 场景有先后依赖（P7 日历回顾用到 P2/P3 造的数据，P6 首页会清空并重建数据，P8 会再清空），按 `tests/e2e/run.mjs` 里的顺序整体跑。

## 目录

